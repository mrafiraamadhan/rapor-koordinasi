# Rapor Koordinasi Kumham Imipas — Purwarupa Indeks Pertanyaan Terjawab

Purwarupa gagasan pendukung esai **Lomba Karya Literasi Hari Bakti ke-2 Kemenko Kumham Imipas** (subtema *Mengawal*).

**Lihat halaman:** https://mrafiraamadhan.github.io/rapor-koordinasi/

## Isi halaman
- Audit 8 pertanyaan publik lintas lembaga dan nilai awal Indeks Pertanyaan Terjawab (0,44).
- Simulator aksi koordinasi dan dampaknya terhadap indeks.
- Grafik data resmi: pelaporan korban kejahatan 2018–2024, data registrasi Polri dibandingkan data survei, hunian lapas, putusan pidana kerja sosial, dan Indeks Pembangunan Hukum.
- Rencana aksi tiga siklus riset aksi (2027–2029).
- Tabel data lengkap dengan tautan sumber, nomor tabel, dan halaman PDF.

## Sumber data
Seluruh angka berasal dari sumber resmi: publikasi *Statistik Kriminal* BPS (edisi 2020–2024/2025), Kemenko Kumham Imipas, Kemenimipas, Ditjenpas, Kepaniteraan Mahkamah Agung, Bappenas, dan peraturan perundang-undangan. Setiap angka di halaman dapat diklik untuk membuka sumbernya.

## Catatan
Halaman ini adalah purwarupa gagasan pribadi penyusun esai dan **tidak mewakili** Kemenko Kumham Imipas, BPS, atau lembaga lain. Penilaian indeks merupakan audit penyusun per 30 September 2026.
